# Insight Grid Web

The public React interface for [Insight Grid](https://insight-grid.sharmaharsh0328.chatgpt.site), a smartphone consumer-intelligence platform built from product specifications, prices, customer reviews, and RoBERTa sentiment data.

## Experience

The interface is organized as a persistent research workspace rather than a traditional dashboard:

- **Overview** summarizes the market and directs users to deeper evidence.
- **Phones** provides complete product, price, specification, and review profiles.
- **Reviews** supports full-text investigation and structured filtering.
- **Finder** recommends phones by budget or use case with explainable scores.
- **Compare** evaluates two devices side by side.
- **Intelligence** provides dataset-grounded brand and market readouts.
- **Actions** connects recurring customer problems with product opportunities.

The embedded assistant retrieves information from the published dataset and exposes supporting product and review records instead of responding from general model knowledge alone.

## Dataset snapshot

- 62 smartphone models
- 14 normalized brands
- 3,031 source reviews
- 2,813 usable reviews after deduplication
- Amazon and Flipkart review evidence

The web application consumes a portable snapshot generated by the shared Python intelligence engine. This keeps calculations consistent between the source database, API, and deployed interface.

## Stack

- React 19 and TypeScript
- Vinext and Vite
- Tailwind CSS and custom responsive components
- Cloudflare Workers deployment through ChatGPT Sites

## Local development

Node.js 22.13 or newer and pnpm are required.

```bash
pnpm install
pnpm dev
```

Build and run the production version:

```bash
pnpm build
pnpm start
```

## Validation

```bash
pnpm run check
```

The check runs linting, a full production build, and product-contract tests covering navigation, accessibility, loading and error states, dataset integrity, evidence links, assistant citations, and private dataset-management boundaries.

## Main directories

```text
app/             # Routes, page components, shared UI, and published snapshot
public/data/     # Browser-accessible review evidence
tests/           # Product and reliability contracts
worker/          # Deployment worker integration
```

Catalog and review updates originate in the parent Python workspace. After approved data changes, `scripts/export_web_snapshot.py` regenerates the data consumed here.
